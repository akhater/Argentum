- **"Find one" for a camera profile no longer depends on GitHub's API, and checks what it
  downloads.** Which RawTherapee profiles exist is now built into the app
  (`mods/rt_profiles.tsv`, 161 profiles at RawTherapee commit `911b0b8e`, generated by
  `scripts/rawtherapee-profiles.mjs`), so the search works offline and no longer fails once GitHub's
  60 calls an hour per network run out. The file is downloaded from that commit and refused unless
  its size and git hash are the ones listed. RawTherapee's other names for a body are read too
  (`camera_model_aliases.json`): a Kiss X7 or Rebel SL1 now finds and uses the EOS 100D profile,
  and 26 more such names their body's. A body with a profile of its own keeps it.
  `npm run check:sources` warns when RawTherapee changes its profiles after that commit.
